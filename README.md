# Лабораторная работа 6: Рефакторинг

## Проблемы исходного кода
- Слишком длинная функция `process_checkout` (70+ строк)
- Смешанные ответственности: парсинг, валидация, расчеты в одной функции
- Много магических чисел и строк
- Сложные вложенные условия для скидок
- 
### 1. Разделение на функции
Исходный код разбит на 13 небольших функций:
- Каждая отвечает за одну задачу
- Улучшена читаемость и тестируемость

### 2. Выделение констант
Все магические значения вынесены в константы:
- Коды купонов и ставки скидок
- Ставка налога и значения по умолчанию
- Пороговые значения для скидок

### 3. Упрощение логики
- Валидация разделена на отдельные проверки
- Логика скидок разложена на отдельные функции
- Основная функция стала читаться как последовательность шагов

## Результат
- Основная функция сокращена до 18 строк
- Код стал понятнее и проще для изменений
- Все тесты проходят без изменений
